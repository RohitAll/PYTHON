# 🧮 Python Calculator

A simple **menu-based calculator** built with Python.
This project is designed to practice Python **functions, loops, conditions, user input, and basic error handling**.

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🚫 Division-by-zero protection
* 🔄 Continuous calculations using a loop
* ❌ Exit option
* 📋 Simple and easy-to-use menu

## 🛠️ Concepts Used

This project uses some important Python concepts:

* Functions
* Parameters and return values
* `while` loop
* `if`, `elif`, and `else`
* User input with `input()`
* Type conversion using `float()`
* f-strings
* `break`
* `continue`
* Basic error handling with conditions

## 💻 How It Works

When you run the program, it shows a menu:

```text
1. Addition
2. Subtraction
3. Multiplication
4. Divide
5. Exit
```

You choose an operation by entering its number.

For example:

```text
Enter your operation: 1
Enter 1st number: 20
Enter 2nd number: 10

Sum = 30
```

The calculator keeps running until you select option `5`.

## 🚫 Division by Zero

The program also checks whether the second number is `0` before performing division.

```text
Enter your operation: 4
Enter 1st number: 10
Enter 2nd number: 0

Cannot divide by zero
```

This prevents the program from producing a division error.
